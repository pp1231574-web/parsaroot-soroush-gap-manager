# ربات مدیریت گپ سروش — پارسا روت

ربات مدیریت گپ با نام **پارسا روت**، ساخته‌شده به‌صورت ماژولار برای اتصال به API رسمی سروش.

> نکته: نام endpointها و ساختار update در نسخه‌های مختلف API سروش ممکن است متفاوت باشد؛ همه این موارد در `.env` قابل تنظیم است.

## امکانات

- سیستم اخطار با محرومیت خودکار
- فیلتر کلمات ممنوع و لینک
- ضد flood و محدودیت سرعت پیام
- نقش‌های مالک، ادمین و عضو
- ثبت رویدادهای مدیریتی در SQLite
- دستورات فارسی و انگلیسی
- حالت امن: فقط مدیران مجاز می‌توانند دستورات مدیریتی را اجرا کنند
- webhook با توکن مخفی

## اجرا

```bash
npm install
cp .env.example .env
# مقادیر .env را تکمیل کنید
npm start
```

آدرس webhook:

```text
POST https://YOUR_DOMAIN/webhook/<WEBHOOK_SECRET>
```

## دستورات

- `/help` — راهنما
- `/rules` — قوانین گپ
- `/warn @user دلیل` — اخطار
- `/warnings @user` — نمایش اخطارها
- `/ban @user دلیل` — مسدودکردن
- `/unban @user` — رفع مسدودی
- `/mute @user 10` — سکوت به دقیقه
- `/unmute @user` — رفع سکوت
- `/setrules متن قوانین` — تنظیم قوانین
- `/settings` — تنظیمات گپ

ربات را ابتدا در گپ به‌عنوان مدیر اضافه کنید و سپس webhook را طبق مستندات API رسمی سروش ثبت کنید.
